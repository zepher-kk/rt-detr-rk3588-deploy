# 常见问题

## 模型加载成功但没有检测结果

先检查 boxes/logits 输出形状和数值范围，再通过单图检测与批量导出确认
后处理语义。不要只依赖模型初始化返回值。

## 150 query 模型无法运行

C++ 主程序支持 150/300 query。当前 Python 推理脚本只支持 300 query，
运行 150 query 模型时请使用 C++ 入口。

## 摄像头格式或吞吐变化

程序会与 V4L2 设备协商格式。不同设备、线缆、USB 模式和系统配置可能得到
不同结果。调试时记录设备节点、实际分辨率、pixel format、stride 和 buffer
数量。

## 模型输出异常

核对模型输入尺寸、预处理方式、输出顺序和类别数。模型转换环境与板端 runtime
需要兼容；模型文件应来自可信的发布位置。

## 视频时长或帧率异常

检查输入是 CFR 还是 VFR，并确认输出帧率设置。错误帧率会改变视频时长和
播放速度。
